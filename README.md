# XPUSH
Xpush - a minecraft fabric 1.21.11 mod for fast punching experience bottles.
# Using
If you activate Xpush with keybind or GUI and you will take experience bottle and hold right mouse button you very quickly break bottles.
# Features
At the time of the 1.1:
Flexable delay,
Development GUI,
KeyBind for activate XPush and open GUI,
Worked XPush System
